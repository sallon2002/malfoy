# 말포이 양은 솔직하지 않다 — 책 리더 홈페이지

아이폰에 맞춘 연재 읽기 사이트예요. 빌드 도구 없이 HTML/CSS/JS 파일만으로 돌아가요.

## 기능
- **서재**: 밤하늘 표지, 이어 읽기 카드, 부별 목차 (새 글 / 읽는 중 % / 다 읽음)
- **읽기**: 종이책처럼 한 장씩 넘겨요. 옆으로 쓸거나 화면 오른쪽/왼쪽을 톡 치면 다음/이전 장, 가운데를 치면 위 막대가 나와요. 마지막 장에서 더 넘기면 다음 화로 가요. 몰입을 깨지 않도록 글자 수·남은 시간은 보여 주지 않고, 아래에 쪽수만 표시해요
- **보기 설정**: 글자 크기 8단계, 줄 간격, 명조/고딕, 종이·세피아·밤 배경
- **이어 읽기**: 읽던 문단을 이 기기에 저장해요. 앱을 껐다 켜면 마지막으로 읽던 화의 그 문단으로 바로 열려요. 글자 크기를 바꿔도 같은 문장으로 돌아와요
- **홈 화면 앱**: 아이폰 Safari에서 공유 → 홈 화면에 추가 (주소창 없이 열리고, 읽던 자리가 가장 오래 기억돼요)

- **KR ⇄ JP**: 표지 오른쪽 위 토글이나 보기 설정에서 언어를 바꿔요. 일본어판은 한국어판과 문단이 1:1이라, 읽는 중에 바꿔도 같은 문단에 머물러요. 일본어 아이폰에서 처음 열면 JP로 시작해요

## 새 화 올리는 법
1. 상위 폴더에 원고를 `02_프롤로그_2화.md`처럼 저장해요 (번호_부_화.md). 둘째 줄은 `## 프롤로그 2화 — 제목` 형식이어야 해요. 일본어판은 `일본어판/02_プロローグ_第2話.md` (`## プロローグ 第2話 — 제목`). 일본어판이 아직 없는 화는 JP 목차에 나오지 않아요.
2. 이 폴더에서 빌드해요.
   ```
   node tools/build.js
   ```
3. 원고 데이터는 열 때마다 새로 받아서, 새 화는 따로 할 일 없이 바로 보여요. 화면(app.js · styles.css)을 고쳤을 때만 `index.html`의 `?v=` 숫자를 바꿔요.

`00_설정집.md`는 스포일러라서 빌드에 절대 들어가지 않아요.

## 파일
| 파일 | 하는 일 |
|---|---|
| `index.html` · `styles.css` · `app.js` | 화면 |
| `data/chapters.js` | 원고에서 만든 데이터 (직접 고치지 않음) |
| `tools/build.js` | 원고 → 데이터 |
| `tools/icons.js` | 홈 화면 아이콘(용자리) 그리기 |
| `tools/serve.js` | 미리보기용 서버 (`node tools/serve.js 4175`) |
